Sobre a Disciplina

Programação Web I PWI

Disciplina do 1 semestre do curso de Desenvolvimento de Sistemas da ETEC. Aqui voce aprende do zero a criar páginas web estaticas utilizando HTML para estruturação, CSS para estilização e JavaScript para interatividade.

HTML5

Estruturação semântica de páginas, formulários, tabelas, multimídia e boas práticas de acessibilidade.

CSS3

Estilização com seletores, flexbox, grid, responsividade, animações e design moderno.

JavaScript

Lógica de programação, manipulação do DOM, eventos, funções e introdução a ES6+.

Ementa

Conteudo Programatico

Unidade I - Fundamentos

  • Historia e funcionamento da web
  • Estrutura basica do HTML
  • Tags semânticas HTML5
  • Formularios e inputs

Unidade II - Estilização

  • Seletores e propriedades CSS
  • Box model e layout
  • Flexbox e Grid
  • Design responsivo

Unidade III - Interatividade

  • Variaveis, tipos e operadores
  • Estruturas de controle
  • Funções e eventos
  • Manipulação do DOM

Unidade IV - Projeto Final

  • Planejamento de página web
  • Integração HTML + CSS + JS
  • Publicação com GitHub Pages
  • Apresentação dos projetos
Este e um resumo do conteudo principal. A ementa completa com todos os tópicos está na documentação oficial do curso.
